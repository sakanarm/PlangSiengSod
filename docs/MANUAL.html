1. โปรแกรมนี้ทำอะไร

โปรแกรมรับเสียงจากไมค์ แปลงเป็นเสียงอื่นทันทีขณะที่คุณพูด (เสียงหุ่นยนต์ เสียงคนแบบอื่น หรือเอฟเฟกต์) แล้วส่งต่อไปยังสายเสียงเสมือน VB-CABLE ซึ่ง Teams จะมองเห็นเป็นไมโครโฟนตัวหนึ่ง

ไมค์จริง→ โปรแกรมนี้ (แปลงเสียง)→ CABLE Input⇒ VB-CABLE ⇒ CABLE Output→ Teams
  • เป็นแบบ real time ไม่ต้องอัดเป็นไฟล์ก่อน ความหน่วงรวมประมาณ ¼ วินาที (ค่าจริงของเครื่องคุณดูได้ในโปรแกรม)
  • เสียงทุกแบบในเวอร์ชันนี้เป็นเอฟเฟกต์เสียง (DSP) ไม่ได้ใช้ AI จึงไม่ต้องโหลดโมเดลและไม่ต้องใช้การ์ดจอ (Robot voice และ Other voices อีก 12 แบบ ดูหัวข้อ 5)
  • โหมดเสียง AI (RVC) ยังอยู่ระหว่างพัฒนา เลยกดเลือกในโปรแกรมไม่ได้
ใช้อย่างโปร่งใส: บอกผู้ร่วมประชุมว่าคุณกำลังใช้เอฟเฟกต์เปลี่ยนเสียง อย่าใช้เพื่อปลอมตัวเป็นคนอื่นหรือทำให้คนอื่นเข้าใจผิดว่าใครเป็นคนพูด

2. ติดตั้ง (ทำครั้งเดียว)

สิ่งที่ต้องมี

  • Windows 10 หรือ 11 (64-bit) ไม่ต้องมีการ์ดจอ NVIDIA
  • Python 3.12 (64-bit) จาก python.org
  • VB-CABLE จาก https://vb-audio.com/Cable/ คุณต้องติดตั้งเอง (ใช้สิทธิ์ administrator และต้องรีบูตเครื่องหลังติดตั้ง) โปรแกรมนี้ไม่ติดตั้งไดรเวอร์ให้เอง

ติดตั้งโปรแกรม

เปิด PowerShell ในโฟลเดอร์ realtimevoice (ดูวิธีในหัวข้อถัดไป) แล้วรัน:

powershell -ExecutionPolicy Bypass -File .\setup.ps1

ใช้พื้นที่ประมาณ 260 MB ทั้งหมดอยู่ในโฟลเดอร์ .venv ในโปรเจกต์ ถ้าลบโฟลเดอร์นี้แล้วต้องรัน setup ใหม่

3. เปิดโปรแกรม

  1. เปิด File Explorer แล้วเข้าไปที่โฟลเดอร์ realtimevoice (โฟลเดอร์ที่มีไฟล์ run.ps1)
  2. คลิกช่อง address bar ด้านบน พิมพ์ powershell แล้วกด Enter จะได้หน้าต่าง PowerShell ที่อยู่ในโฟลเดอร์นี้แล้ว
  3. รันคำสั่ง: 
    powershell -ExecutionPolicy Bypass -File .\run.ps1

อย่าปิดหน้าต่าง PowerShell ระหว่างใช้งาน เพราะจะทำให้โปรแกรมปิดตาม

4. เริ่มใช้งานใน 5 ขั้นตอน

  1. Microphone (input) เลือกไมค์จริงของคุณ
  2. กด Use VB-CABLE ช่อง Output → Teams จะเปลี่ยนเป็น CABLE Input (VB-Audio Virtual Cable) ให้เอง
  3. เลือก Robot voice v1 หรือ Other voices / เสียงอื่น (แล้วเลือกเสียงในช่อง Voice / เสียง) แล้วกด Start สถานะจะเปลี่ยนเป็น Processing สีน้ำเงิน
  4. ใน Teams ไปที่ Settings → Devices → Microphone แล้วเลือก CABLE Output (VB-Audio Virtual Cable)
  5. บอกผู้ร่วมประชุมว่ากำลังใช้เอฟเฟกต์เสียง
โปรแกรมจะจำอุปกรณ์และค่าที่ตั้งไว้ทุกครั้งที่กด Start และตอนปิดโปรแกรม เปิดครั้งหน้าไม่ต้องตั้งใหม่

กรอบ Audio routing (เส้นทางเสียง)

ช่อง / ปุ่มใช้ทำอะไร
Microphone (input)ไมค์จริง ห้ามเลือก CABLE Output เพราะจะเกิดเสียงวนกลับ (feedback) และโปรแกรมจะไม่ยอมให้เริ่ม
Output → Teamsเลือก CABLE Input (VB-Audio Virtual Cable) (อย่าเลือกตัวที่มีคำว่า 16ch)
Monitor (headphones)ถ้าอยากได้ยินเสียงที่แปลงแล้วของตัวเอง ให้เลือกหูฟัง ถ้าใช้ลำโพงจะเกิดเสียงสะท้อน ไม่ใช้ให้ตั้งเป็น (off)
Refresh devicesโหลดรายการอุปกรณ์ใหม่ เช่น หลังเสียบไมค์หรือหูฟัง (ต้องกด Stop ก่อน)
Use VB-CABLEตั้ง Output เป็น CABLE Input ให้อัตโนมัติ
Test beep → outputเล่นเสียงบี๊บไปที่ output ถ้าเป็น CABLE Input แถบระดับเสียงของ CABLE Output ใน Windows Sound settings หรือใน Teams ควรขยับ
Test beep → monitorเล่นเสียงบี๊บที่หูฟัง เพื่อเช็กว่าเลือกถูกตัว

กรอบ Levels & output

  • แถบ Input / Output แสดงความดัง (dBFS) ของเสียงเข้าและเสียงออก สีเขียวคือปกติ สีเหลืองคือค่อนข้างดัง สีแดงคือดังเกินจนเสียงอาจแตก
  • Output gain (dB) −24 ถึง +12 ใช้เพิ่มหรือลดเสียงที่ส่งออก ถ้าแถบ Output ขึ้นสีแดงบ่อยให้ลดลง
  • Noise gate (dB, −60=off) ตัดเสียงที่เบากว่าค่านี้ เช่นเสียงพัดลมตอนไม่ได้พูด ลองเริ่มที่ −45 ถ้าตั้งสูงเกินไปเสียงพูดจะขาดหาย

ปุ่มควบคุมและตัวเลขสถิติ

  • Start เริ่มแปลงเสียง โปรแกรมจะตรวจการตั้งค่าก่อน ถ้ามีปัญหาจะบอกในช่อง Messages
  • Stop หยุดแปลงเสียง (ถ้ากำลังอัดเสียงอยู่จะบันทึกไฟล์ให้ด้วย)
  • ● Record บันทึกเสียงที่แปลงแล้วเป็นไฟล์ ดูหัวข้อ 7

ข้อความข้างปุ่มเป็นค่าที่วัดจริงขณะทำงาน:

ค่าความหมายค่าที่ดี
processing … msเวลาที่ใช้แปลงเสียงแต่ละช่วง (ช่วงละ 50 ms)น้อยกว่า 50 มาก
RTFเวลาประมวลผลเทียบกับเวลาจริงน้อยกว่า 1
latency ~… ms + deviceความหน่วงในโปรแกรม บวกกับความหน่วงของอุปกรณ์ที่ Windows รายงาน—
droppedช่วงเสียงที่ต้องทิ้งเพราะประมวลผลไม่ทัน0
underrunsจังหวะที่เสียงขาดช่วง ได้ยินเป็นเสียงกระตุก0 หรือเพิ่มขึ้นช้ามาก
errorsจำนวนครั้งที่ประมวลผลผิดพลาด0
CPU / RAMการใช้ CPU ของทั้งเครื่องและของโปรแกรม และหน่วยความจำที่โปรแกรมใช้—

6. ตั้งค่า Microsoft Teams

  1. ใน Teams กด … (Settings and more) → Settings → Devices
  2. Microphone: เลือก CABLE Output (VB-Audio Virtual Cable)
  3. Speaker: เลือกหูฟังหรือลำโพงตามปกติ ห้ามเลือก CABLE
  4. Noise suppression: ตั้งเป็น Off หรือ Low เพราะระบบตัดเสียงรบกวนของ Teams อาจตัดเสียงหึ่งของ robot หรือเสียงกระซิบจนขาดเป็นช่วงๆ
  5. กด Make a test call เพื่อฟังเสียงที่คนอื่นจะได้ยิน
ถ้าไม่เจอ CABLE Output ใน Teams ให้ปิด Teams แล้วเปิดใหม่ (หลังจากติดตั้ง VB-CABLE และรีบูตแล้ว) ระหว่างประชุมเปลี่ยนกลับไปใช้ไมค์จริงใน Teams ได้ทุกเมื่อ

ทดสอบก่อนเข้าประชุมจริง

ขั้นที่ 1: เช็กว่าเสียงไปถึง VB-CABLE (ยังไม่ต้องเปิด Teams)

  1. ในโปรแกรมนี้ กด Start แล้วพูด แถบ Output ต้องขยับ
  2. เปิด Windows Settings → System → Sound → Input → เลือก CABLE Output ตอนพูด แถบระดับเสียงของ CABLE Output ต้องขยับ ถ้าขยับแสดงว่าเสียงไปถึงสายเสมือนแล้ว

ขั้นที่ 2: ฟังเสียงตัวเองผ่าน Teams (test call)

  1. ให้โปรแกรมนี้อยู่ในสถานะ Processing ไว้
  2. ใน Teams ไปที่ Settings → Devices ตั้ง Microphone เป็น CABLE Output ตอนพูด แถบระดับเสียงใต้ช่อง Microphone ใน Teams ควรขยับ
  3. กด Make a test call แล้วพูดหลังเสียงสัญญาณ Teams จะเล่นเสียงที่อัดไว้กลับมาให้ฟัง เสียงนั้นคือเสียงที่คนในประชุมจะได้ยิน
  4. ระหว่าง test call ให้ตั้ง Monitor ในโปรแกรมนี้เป็น (off) จะได้ไม่สับสนกับเสียงตัวเองที่ได้ยินจากหูฟัง

ขั้นที่ 3 (ไม่บังคับ): ลองกับเพื่อน สร้างประชุมด้วย Meet now แล้วชวนเพื่อนหรือใช้บัญชี/อุปกรณ์อีกเครื่องเข้าร่วม เพื่อฟังเสียงจากอีกฝั่งจริงๆ ถ้าทดสอบด้วยมือถือในห้องเดียวกัน ให้ปิดเสียงลำโพงมือถือหรือใส่หูฟัง จะได้ไม่มีเสียงหอน

บางบัญชีหรือบางเวอร์ชันของ Teams (เช่น Teams แบบส่วนตัว/ฟรี) อาจไม่มีปุ่ม Make a test call ให้ใช้ขั้นที่ 3 แทน

7. บันทึกเสียงเป็นไฟล์

  1. กด Start ให้โปรแกรมทำงานก่อน (ปุ่ม Record จะกดได้หลังจากนั้น)
  2. กด ● Record แล้วเลือกที่เก็บไฟล์ ชื่อไฟล์จะตั้งตามวันเวลาให้อัตโนมัติ เช่น rtvc_20261017_143005.wav โฟลเดอร์เริ่มต้นคือ realtimevoice\recordings\
  3. พูดได้เลย ปุ่มจะแสดงเวลาที่อัดไปแล้ว เช่น ■ Stop recording (12 s)
  4. กด ■ Stop recording (หรือกด Stop) เพื่อจบ ช่อง Messages จะแสดงตำแหน่งไฟล์
  • ไฟล์ที่ได้คือเสียงที่ส่งออกไป Teams ทุกอย่าง รวมถึง gain ด้วย
  • รูปแบบไฟล์เป็น WAV 48 kHz, mono, 16-bit เปิดได้กับโปรแกรมเล่นเสียงทั่วไป
  • ระหว่างอัด เสียงยังส่งเข้า Teams ตามปกติ
  • ไฟล์อยู่ในเครื่องเท่านั้น ไม่มีการอัปโหลด และจะอัดก็ต่อเมื่อคุณกดปุ่มเท่านั้น
ถ้าจะอัดเสียงคนอื่นในการประชุม ต้องขออนุญาตก่อน (ปุ่มนี้อัดเฉพาะเสียงของคุณที่แปลงแล้ว ไม่ได้อัดเสียงคนอื่นในประชุม)

8. แท็บ Hardware

  • Run diagnostics แสดงข้อมูลเครื่อง ได้แก่ เวอร์ชัน Windows, CPU, RAM, การ์ดจอ, อุปกรณ์เสียง และสถานะว่าติดตั้ง VB-CABLE แล้วหรือยัง ใช้แนบไปตอนขอความช่วยเหลือได้
  • Test GPU (DirectML) inference ทดสอบว่าการ์ดจอประมวลผล AI ได้จริงไหม ปุ่มนี้ใช้ได้เฉพาะเมื่อติดตั้งส่วนเสริม AI แล้ว ส่วนเสียง robot ไม่ต้องใช้การ์ดจอ

9. คำสั่งเพิ่มเติม (รันในโฟลเดอร์ realtimevoice)

คำสั่งทำอะไร
powershell -ExecutionPolicy Bypass -File .\run.ps1เปิดโปรแกรม
… .\run.ps1 -CableTestทดสอบ VB-CABLE ด้วยเสียงบี๊บ และลองแปลงเสียงจากไมค์ 5 วินาที แล้วแสดงผลว่า PASS หรือ FAIL
… .\run.ps1 -Diagnosticsแสดงรายงานฮาร์ดแวร์ในหน้าต่าง PowerShell
… .\run.ps1 -Testรัน unit test (ต้องติดตั้งด้วย setup.ps1 -Dev ก่อน)

10. แก้ปัญหา

อาการวิธีแก้
สถานะเป็น Not configuredอ่านเหตุผลที่แสดงข้างสถานะ ส่วนใหญ่เกิดจากยังไม่ได้เลือก output ให้กด Use VB-CABLE
"VB-CABLE was not found"ติดตั้ง VB-CABLE แล้วรีบูต จากนั้นกด Refresh devices
Error "Feedback loop"ช่อง Microphone เลือกเป็น CABLE Output อยู่ ให้เปลี่ยนเป็นไมค์จริง
Teams ไม่ได้ยินเสียงไมค์ใน Teams ต้องเป็น CABLE Output และ Output ในโปรแกรมต้องเป็น CABLE Input (ไม่ใช่ตัว 16ch) สถานะต้องเป็น Processing และแถบ Output ต้องขยับ ลองกด Test beep → output ด้วย
แถบ Input ไม่ขยับไปที่ Windows Settings → Privacy & security → Microphone แล้วเปิดสิทธิ์ให้ desktop apps เช็กว่าเลือกไมค์ถูกตัว และไมค์ไม่ได้ถูกปิดเสียงด้วยปุ่มบนเครื่อง
เสียง robot หรือเสียงกระซิบใน Teams ขาดเป็นช่วงๆตั้ง Noise suppression ใน Teams เป็น Off หรือ Low
เสียงแตกหรือกระตุก และค่า underruns เพิ่มขึ้นเครื่องทำงานหนักเกินไป ให้ปิดโปรแกรมที่ใช้ทรัพยากรมาก หรือแก้ output_prebuffer_blocks ใน config.json จาก 1 เป็น 2 (ความหน่วงจะเพิ่มขึ้นประมาณ 50 ms)
"Could not open audio device"มีโปรแกรมอื่นจองอุปกรณ์ไว้ ให้ไปที่ Sound Control Panel → เลือกอุปกรณ์ → Advanced → เอาเครื่องหมายออกจาก Allow applications to take exclusive control หรือตั้งเป็น 48000 Hz
Error: device stopped / disconnectedไมค์หรือหูฟัง USB/Bluetooth หลุด ให้เสียบใหม่ กด Refresh devices แล้ว Start
ได้ยินเสียงตัวเองสะท้อนMonitor ส่งเสียงออกลำโพงอยู่ ให้ใช้หูฟังหรือตั้ง Monitor เป็น (off)
หูฟัง Bluetooth เสียงแย่ลงทันทีBluetooth จะสลับไปโหมดคุณภาพต่ำเมื่อใช้ไมค์ของหูฟัง ให้ใช้ไมค์ในตัวโน้ตบุ๊กหรือไมค์แบบสาย/USB แทน
เปิดโปรแกรมไม่ขึ้นรัน setup.ps1 ใหม่ แล้วดูรายละเอียดใน logs\rtvc.log
อยากล้างค่าที่ตั้งไว้ทั้งหมดปิดโปรแกรมแล้วลบไฟล์ config.json (ไฟล์นี้เก็บแค่ค่าที่ตั้งไว้)

11. ไฟล์ของโปรแกรมและความเป็นส่วนตัว

ไฟล์ / โฟลเดอร์เก็บอะไร
config.jsonอุปกรณ์และค่าที่ตั้งไว้
logs\rtvc.logบันทึกการทำงานและข้อผิดพลาด (ไม่มีเสียงอยู่ในไฟล์นี้)
recordings\ไฟล์เสียงที่คุณกดบันทึก (ถ้าเลือกเก็บที่โฟลเดอร์เริ่มต้น)

  • ไฟล์เสียงและ config ถูกใส่ไว้ใน .gitignore แล้ว จึงไม่หลุดเข้า git
