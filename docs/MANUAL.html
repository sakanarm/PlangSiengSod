คู่มือการใช้งาน Parroty

เปลี่ยนเสียงพูดเป็นเสียงหุ่นยนต์ เสียงคนแบบอื่น หรือเอฟเฟกต์ แบบ real time แล้วส่งเข้า Microsoft Teams, Zoom, Discord และโปรแกรมโทรอื่นบน Windows

เวอร์ชัน 0.2 (lite) Windows 10 / 11 · 64-bit ไม่ต้องใช้การ์ดจอ ประมวลผลในเครื่องทั้งหมด

01โปรแกรมนี้ทำอะไร

โปรแกรมรับเสียงจากไมค์ แปลงเป็นเสียงอื่นทันทีขณะที่คุณพูด แล้วส่งต่อไปยังสายเสียงเสมือน VB-CABLE ซึ่ง Teams จะมองเห็นเป็นไมโครโฟนตัวหนึ่ง

ไมค์จริงในตัว / สาย / USB → Parrotyแปลงเสียง → CABLE InputVB-CABLE ⇒ CABLE Outputไมค์เสมือน → Teams / Zoom / …

เสียงจากตัวอย่าง (ใหม่ใน v0.2)

วัดระดับเสียง ขนาดช่องเสียง และโทนเสียงจากไฟล์หรือเสียงที่อัด แล้วสร้างเป็นเสียงใหม่ของคุณ ใช้แบบ real time ใน Teams ได้ ดูหัวข้อ 07

เสียง AI (RVC)

ยังอยู่ระหว่างพัฒนาและไม่มีใน v0.2 จึงกดเลือกในโปรแกรมไม่ได้

ใช้อย่างโปร่งใส บอกผู้ร่วมประชุมว่าคุณกำลังใช้เอฟเฟกต์เปลี่ยนเสียง อย่าใช้เพื่อปลอมตัวเป็นคนอื่น หรือทำให้คนอื่นเข้าใจผิดว่าใครเป็นคนพูด

ขั้น 1 · ดาวน์โหลดโปรแกรม

เลือกวิธีใดวิธีหนึ่ง:

  1. ดาวน์โหลด ZIP: เปิดหน้าโปรเจกต์บน GitHub (github.com/sakanarm/PlangSiengSod) กด Code → Download ZIP แล้วคลิกขวาไฟล์ ZIP → Extract All… แนะนำให้แตกไฟล์ไว้ในโฟลเดอร์ของคุณเอง เช่น Documents หรือ Desktop ไม่ควรไว้ใน Program Files
  2. หรือใช้ git (ถ้ามี git อยู่แล้ว): 
    git clone https://github.com/sakanarm/PlangSiengSod.git

โฟลเดอร์ที่ได้ (มีไฟล์ setup.ps1 และ run.ps1) จะเรียกว่า โฟลเดอร์โปรแกรม ในคู่มือนี้

ขั้น 2 · ติดตั้ง Python 3.12 (64-bit)

  1. ไปที่ python.org/downloads/windows เลือก Python 3.12.x → Windows installer (64-bit) ต้องเป็นเวอร์ชัน 3.12 เท่านั้น สคริปต์ติดตั้งจะเรียก py -3.12
  2. เปิดตัวติดตั้ง ที่หน้าแรกให้ติ๊ก Add python.exe to PATH และตรวจว่าติ๊ก py launcher ไว้ จากนั้นกด Install Now
  3. ตรวจผล: เปิด PowerShell หน้าต่างใหม่แล้วรัน 
    py -3.12 --version
    ต้องได้ข้อความ Python 3.12.x ถ้าขึ้นว่าไม่รู้จักคำสั่ง py ให้ติดตั้งใหม่และติ๊ก py launcher

ขั้น 3 · ติดตั้ง VB-CABLE (คุณต้องติดตั้งเอง)

ต้องใช้สิทธิ์ administrator และรีบูต VB-CABLE เป็นไดรเวอร์เสียงของ VB-Audio Software การติดตั้งไดรเวอร์ต้องให้คุณยืนยันเอง Parroty และสคริปต์ setup จะไม่ติดตั้งไดรเวอร์ให้ ถ้าเป็นเครื่องบริษัท อาจต้องขอให้ฝ่าย IT ติดตั้งให้
  1. ดาวน์โหลดแพ็กเกจทางการจาก vb-audio.com/Cable (ไฟล์ ZIP สำหรับ Windows) อย่าโหลดจากเว็บอื่น
  2. คลิกขวาไฟล์ ZIP → Extract All… (ต้องแตกไฟล์ก่อน รันจากใน ZIP ไม่ได้)
  3. คลิกขวา VBCABLE_Setup_x64.exe → Run as administrator → กด Install Driver → ยืนยันหน้าต่างของ Windows
  4. รีบูตเครื่อง
  5. ตรวจผล: Settings → System → Sound ฝั่ง Output ต้องมี CABLE Input (VB-Audio Virtual Cable) และฝั่ง Input ต้องมี CABLE Output (VB-Audio Virtual Cable)
อย่าตั้ง CABLE เป็นลำโพงหลักของ Windows หลังติดตั้ง Windows อาจเปลี่ยนลำโพงหลักเป็น CABLE Input ทำให้เครื่องเงียบ ถ้าเป็นแบบนี้ ให้ไปที่ Settings → System → Sound แล้วเลือกลำโพงหรือหูฟังจริงกลับเป็น Output ตามเดิม

ขั้น 4 · ตั้งค่าเสียงของ Windows

  1. 48 kHz (แนะนำ): Settings → System → Sound → More sound settings (Sound Control Panel) → แท็บ Playback คลิกขวา CABLE Input → Properties → Advanced → เลือกรูปแบบที่เป็น 48000 Hz แล้วทำแบบเดียวกันกับ CABLE Output ในแท็บ Recording และกับไมค์ของคุณ
  2. สิทธิ์ไมโครโฟน: Settings → Privacy & security → Microphone เปิด Microphone access และ Let desktop apps access your microphone

ขั้น 5 · ติดตั้งโปรแกรม (setup.ps1)

  1. เปิด PowerShell ในโฟลเดอร์โปรแกรม (วิธีอยู่ในหัวข้อ 04 ข้อ 1–2)
  2. รันคำสั่ง: 
    powershell -ExecutionPolicy Bypass -File .\setup.ps1
    -ExecutionPolicy Bypass อนุญาตให้รันสคริปต์นี้เฉพาะครั้งนี้ ไม่ได้เปลี่ยนการตั้งค่าความปลอดภัยของเครื่อง
  3. รอจนขึ้น == Done ถ้าขึ้นว่า VB-CABLE found. แสดงว่าพร้อมใช้งาน
setup.ps1 ทำอะไรบ้าง
ตรวจ Python
ตรวจว่ามี Python 3.12 แบบ 64-bit ถ้าไม่มีจะหยุดและบอกวิธีติดตั้ง
สร้าง .venv
สร้างสภาพแวดล้อม Python แยกไว้ในโฟลเดอร์ .venv ของโปรแกรม ไม่ยุ่งกับ Python หลักของเครื่อง ถ้ามีอยู่แล้วจะใช้ของเดิม
ติดตั้งไลบรารี
ติดตั้งแพ็กเกจตามเวอร์ชันที่ระบุใน requirements.txt (ประมาณ 330 MB) ต้องต่ออินเทอร์เน็ต
ตรวจ VB-CABLE
แค่ตรวจว่าติดตั้งแล้วหรือยัง ถ้ายังจะแจ้งวิธีติดตั้ง แต่ไม่ติดตั้งให้
ตัวเลือกเพิ่มเติมของ setup.ps1
-Dev
ติดตั้ง pytest เพิ่ม สำหรับรัน unit test (run.ps1 -Test)
-Recreate
ลบ .venv แล้วสร้างใหม่ ใช้เมื่อการติดตั้งเสีย ถ้าไม่ใส่ตัวเลือกนี้สคริปต์จะไม่ลบ .venv
-WithAI / -WithRMVPE
ส่วนเสริม AI ที่ยังทดลองอยู่ (ดูหัวข้อ 02) ผู้ใช้ทั่วไปไม่ต้องใส่

ทดสอบหลังติดตั้ง

powershell -ExecutionPolicy Bypass -File .\run.ps1 -CableTest

คำสั่งนี้ทดสอบ VB-CABLE ด้วยเสียงบี๊บ และลองแปลงเสียงจากไมค์ 5 วินาที ถ้าผลเป็น PASS แสดงว่าเส้นทางเสียงพร้อมใช้กับ Teams ถ้าเป็น FAIL ให้อ่านข้อความที่แสดงและดูหัวข้อ 12

04เปิดโปรแกรม

หลังติดตั้งครั้งแรก (หัวข้อ 03) เปิดโปรแกรมแบบดับเบิลคลิกได้เลย ไม่ต้องพิมพ์คำสั่ง

Parroty.exe
ดับเบิลคลิกในโฟลเดอร์โปรแกรม มีไอคอนนกแก้ว เปิดโปรแกรมโดยไม่มีหน้าต่างดำค้าง ถ้ายังไม่มีไฟล์นี้ ให้รัน scripts\build_launcher.ps1 ครั้งเดียว
Parroty.cmd
ดับเบิลคลิกได้เหมือนกัน ใช้แทน Parroty.exe ได้ทุกเครื่อง ถ้ายังไม่ได้ติดตั้งจะบอกให้รัน setup.ps1 ก่อน
Shortcut
รัน scripts\make_shortcuts.ps1 ครั้งเดียว จะได้ไอคอน Parroty ที่ Desktop และ Start menu (ไม่ต้องใช้สิทธิ์ admin) คลิกขวาที่ไอคอนเพื่อ Pin to taskbar ได้

หรือเปิดผ่าน PowerShell แบบเดิม (ใช้ดูข้อความผิดพลาดได้ ถ้าเปิดแบบดับเบิลคลิกแล้วไม่ขึ้น):

  1. เปิด File Explorer แล้วเข้าไปที่โฟลเดอร์โปรแกรม (โฟลเดอร์ที่มีไฟล์ run.ps1)
  2. คลิกช่อง address bar ด้านบน พิมพ์ powershell แล้วกด Enter จะได้หน้าต่าง PowerShell ที่อยู่ในโฟลเดอร์นี้แล้ว
  3. รันคำสั่ง: 
    powershell -ExecutionPolicy Bypass -File .\run.ps1
ถ้าเปิดผ่าน PowerShell อย่าปิดหน้าต่าง PowerShell ระหว่างใช้งานต้องเปิดหน้าต่าง PowerShell ทิ้งไว้ ถ้าปิดโปรแกรมจะปิดตาม (ย่อหน้าต่างไว้ได้) ถ้าเปิดด้วย Parroty.exe หรือ Parroty.cmd ไม่มีหน้าต่างนี้

05เริ่มใช้งานใน 5 ขั้นตอน

ตั้งค่าครั้งแรกครั้งเดียว ครั้งต่อไปเปิดโปรแกรมแล้วกด Start ได้เลย

  1. ไปที่หน้า Audio devices · อุปกรณ์ (เมนูด้านซ้าย) แล้วเลือก Microphone (input) เป็นไมค์จริงของคุณ
  2. กด Use VB-CABLE ช่อง Output → Teams จะเปลี่ยนเป็น CABLE Input (VB-Audio Virtual Cable) ให้เอง
  3. กลับไปหน้า Voice · เสียง คลิกเลือกเสียงที่ต้องการ แล้วกด ▶ Start สถานะจะเปลี่ยนเป็น Processing และปุ่มจะกลายเป็น ■ Stop
  4. ใน Teams ไปที่ Settings → Devices → Microphone แล้วเลือก CABLE Output (VB-Audio Virtual Cable)

07สร้างเสียงจากตัวอย่าง (Voice from sample)

วัดระดับเสียง ขนาดช่องเสียง (formant) และโทนเสียงของเสียงต้นแบบสั้นๆ เทียบกับเสียงของคุณ แล้วบันทึกเป็นเสียงใหม่ในหมวด My voices · เสียงของฉัน เสียงใหม่ทำงานแบบ real time เหมือนเสียงอื่นทุกแบบ ใช้กับ Teams, Zoom และโปรแกรมโทรอื่นได้ (ส่งออกทาง CABLE Input เหมือนเดิม) ส่วนการวิเคราะห์ทำครั้งเดียวตอนสร้างเสียง

ได้เสียงที่ใกล้เคียงขึ้น ไม่ใช่เสียงของคนนั้น เป็นเอฟเฟกต์ DSP (เลื่อน pitch, formant และปรับ EQ) ไม่ใช่ AI โคลนเสียง จังหวะ สำเนียง และวิธีพูดยังเป็นของคุณ ใช้เฉพาะเสียงของคุณเอง หรือเสียงที่เจ้าของอนุญาตแล้ว และห้ามใช้เพื่อแอบอ้างเป็นคนอื่นหรือทำให้ผู้ร่วมประชุมเข้าใจผิดว่าใครพูด โปรแกรมจะให้ติ๊กยืนยันก่อนวิเคราะห์ทุกครั้งที่เปิดโปรแกรม

ขั้นตอน

  1. เปิดหน้า Voice from sample · เสียงจากตัวอย่าง ที่เมนูซ้าย อ่านข้อความ แล้วติ๊ก I confirm · ยืนยัน
  2. 1. Reference · ต้นแบบ กด Choose file… แล้วเลือกไฟล์ WAV, WebM, MP3, M4A, OGG, FLAC หรือ Opus (หรือกด ● Record เพื่ออัดจากไมค์) ควรเป็นเสียงพูดของคนเดียว 10–20 วินาที ไม่มีดนตรีหรือเสียงรบกวน ถ้าไฟล์ยาวกว่า 60 วินาที โปรแกรมใช้แค่ 60 วินาทีแรก
  3. 2. Your voice · เสียงคุณ กด ● Record แล้วพูดตามปกติ 10–20 วินาทีด้วยไมค์ที่ใช้โทรจริง (ไมค์ที่เลือกไว้ในหน้า Audio devices) กด ■ Stop เมื่อพอ หรือรอให้หยุดเองที่ 20 วินาที ต้องกด Stop ที่หน้า Voice ก่อน เพราะใช้ไมค์พร้อมกันสองงานไม่ได้ เลือกเป็นไฟล์ก็ได้เช่นกัน
  4. 3. Analyze กด Analyze รอไม่กี่วินาที ปุ่มจะกดได้เมื่อมีเสียงครบทั้งสองช่องและติ๊กยืนยันแล้ว
  5. 4. Listen · ฟังเปรียบเทียบ กด ▶ Reference, ▶ Yours และ ▶ Matched (เสียงของคุณหลังผ่านเสียงใหม่) ปุ่ม ■ หยุดเล่น เล่นที่หูฟังที่ตั้งเป็น Monitor หรือลำโพงหลักของ Windows ถ้า Monitor เป็น (off) ไม่ส่งเข้า Teams
  6. 5. Save ตั้งชื่อ แล้วกด Save โปรแกรมจะเลือกเสียงใหม่และพาไปหน้า Voice จากนั้นกด Start แล้วพูดใน Teams ได้ทันที

ตารางผลการวัด

ทุกค่าในตารางวัดจากเสียงจริง คอลัมน์ After matching · หลังปรับ คือเสียงของคุณที่ผ่านเสียงใหม่แล้วนำมาวัดซ้ำ ไม่ใช่ค่าที่คาดเดา ตัวเลขที่ใกล้กันไม่ได้แปลว่าฟังเหมือนกัน ควรฟังเปรียบเทียบด้วย

ค่าความหมาย
Pitch, medianระดับเสียงกลางของช่วงที่พูด (Hz) ใช้กำหนดแถบ Pitch
Pitch range (10–90 %)ช่วงเสียงขึ้นลงตอนพูด
Formant F1, F2, F3ความถี่เรโซแนนซ์ของช่องเสียง ค่าสูง = ช่องเสียงสั้น ฟังตัวเล็ก ใช้กำหนดแถบ Formant
Tone slope (dB/oct)ความลาดของโทน ติดลบมาก = ทุ้มนุ่ม ติดลบน้อย = ใสสว่าง
Brightness (spectral centroid)จุดกึ่งกลางพลังงานของเสียง ค่าสูง = เสียงสว่าง
Speech with pitchจำนวนวินาทีที่วัดระดับเสียงได้ ถ้าน้อยกว่า 3 วินาที ค่าจะไม่น่าเชื่อถือ
Speech levelความดังเฉลี่ยตอนพูด (dBFS) เบากว่า −45 ถือว่าเบาเกินไป

ข้อความสีเหลือง ⚠ ใต้ตารางคือคำเตือน เช่น ไฟล์สั้นเกินไป เสียงเบาเกินไป เสียงแตก (clipped) หรือค่าที่ต้องปรับเกินขีดจำกัด

ค่าที่ได้และการปรับต่อ

Pitch ±12
12 × log₂(pitch ต้นแบบ ÷ pitch ของคุณ) ถ้าต่างกันเกิน 1 อ็อกเทฟจะถูกจำกัดไว้ที่ ±12
Formant ±8
ค่าเฉลี่ยของอัตราส่วน F1–F3 ระหว่างต้นแบบกับเสียงของคุณ
Tone EQ
20 ช่วงความถี่ 100 Hz – 8 kHz ปรับโทนให้ใกล้ต้นแบบหลังเลื่อน pitch และ formant แล้ว เพิ่มได้สูงสุด +6 dB ลดได้สูงสุด −10 dB เพื่อไม่ให้เสียงซ่าเพิ่ม

หลังบันทึก แถบ Pitch, Formant และ Tone match (EQ amount) ในหน้า Voice ยังปรับต่อได้ทันทีแม้กำลังทำงาน ปุ่ม Reset to preset คืนค่าที่วัดได้ ส่วน Delete voice ลบเสียงนั้น

Real time: ความหน่วงและ CPU เสียงใน My voices หน่วงในตัวประมาณ 64 ms (มากกว่าเสียงคนแบบอื่น 21 ms เพราะมี EQ) บวกความหน่วงของอุปกรณ์ บนเครื่องทดสอบ ใช้เวลาประมวลผลประมาณ 3–4 ms ต่อช่วงเสียง 50 ms เท่ากับเสียงอื่น
ให้ได้ผลดีขึ้น ใช้ไฟล์ต้นแบบที่มีแต่เสียงพูดของคนเดียว อัดเสียงของคุณด้วยไมค์และห้องเดียวกับที่ใช้โทรจริง ถ้าเสียงต้นแบบกับเสียงของคุณต่างกันมาก ผลจะฟังออกว่าผ่านเอฟเฟกต์ ถ้าเสียงซ่าหรือแหลมเกินไป ให้ลด Tone match ลง
ไม่เก็บไฟล์เสียง เสียงต้นแบบและเสียงที่อัดอยู่ในหน่วยความจำเท่านั้น และหายไปเมื่อปิดโปรแกรม ไม่มีการส่งขึ้นอินเทอร์เน็ต เสียงใหม่เก็บเป็นตัวเลขอย่างเดียว (pitch, formant, EQ และค่าที่วัดได้) ในโฟลเดอร์ custom_voices\

08ตั้งค่า Microsoft Teams และโปรแกรมอื่น

Teams ต้องใช้ “ไมค์เสมือน” CABLE Output แทนไมค์จริง ส่วนลำโพงยังใช้ของจริงตามปกติ

  1. ใน Teams กด … (Settings and more) → Settings → Devices
  2. Microphone: เลือก CABLE Output (VB-Audio Virtual Cable)
  3. Speaker: เลือกหูฟังหรือลำโพงตามปกติ ห้ามเลือก CABLE
  4. Noise suppression: ตั้งเป็น Off หรือ Low เพราะระบบตัดเสียงรบกวนของ Teams อาจตัดเสียงหึ่งของ robot หรือเสียงกระซิบจนขาดเป็นช่วงๆ
  5. กด Make a test call เพื่อฟังเสียงที่คนอื่นจะได้ยิน
ไม่เจอ CABLE Output ใน Teams? ปิด Teams แล้วเปิดใหม่ (หลังจากติดตั้ง VB-CABLE และรีบูตแล้ว) · ระหว่างประชุมเปลี่ยนกลับไปใช้ไมค์จริงใน Teams ได้ทุกเมื่อ

ฟังเสียงตัวเองก่อนเข้าประชุม (คนอื่นจะได้ยินแบบไหน)

0 · Test my voice
ง่ายที่สุด ไม่ต้องกด Start: หน้า Voice ใต้แถบสถานะ เลือกเสียง กด ● Speak 5 s แล้วพูด 5 วินาที (กดซ้ำเพื่อหยุดก่อนได้) โปรแกรมจะเล่นกลับเป็นเสียงที่เลือกทางหูฟัง Monitor หรือลำโพงหลักของ Windows (ไม่ส่งเข้า Teams) จากนั้นเลือกเสียงอื่นหรือปรับแถบ แล้วกด ▶ Play again เพื่อฟังประโยคเดิมด้วยเสียงใหม่ได้ทันที เสียงที่อัดเก็บไว้ในหน่วยความจำเท่านั้น ไม่บันทึกเป็นไฟล์ ใช้ไม่ได้ระหว่างที่กด Start อยู่ (ไมค์ถูกใช้งาน)
1 · Monitor (headphones)
หน้า Audio devices ตั้ง Monitor เป็นหูฟัง แล้วกด Start ขณะพูดจะได้ยินเสียงที่แปลงแล้วทันที ลองสลับเสียงและปรับแถบไปพร้อมกันได้ ต้องใช้หูฟัง ถ้าใช้ลำโพงจะเกิดเสียงสะท้อน เสียงที่ได้ยินคือเสียงเดียวกับที่ส่งเข้า Teams
2 · ● Record
กด Start → Record → พูด 5–10 วินาที → Stop recording แล้วเปิดไฟล์ .wav ฟัง (หัวข้อ 09) เหมาะกับการเทียบหลายเสียง หรือเมื่อไม่มีหูฟัง
3 · Make a test call
ใน Teams (ขั้นที่ 2 ด้านล่าง) Teams อัดเสียงที่ได้รับจาก CABLE Output แล้วเล่นกลับให้ฟัง ตรงกับที่คนในประชุมได้ยินที่สุด รวมผลของ Noise suppression ของ Teams ด้วย

09บันทึกเสียงเป็นไฟล์

อัดเสียงที่แปลงแล้วเก็บไว้ฟังเอง เช่น ไว้เทียบเสียงแต่ละแบบ

  1. กด ▶ Start ให้โปรแกรมทำงานก่อน (ปุ่ม Record จะกดได้หลังจากนั้น)
  2. กด ● Record แล้วเลือกที่เก็บไฟล์ ชื่อไฟล์จะตั้งตามวันเวลาให้อัตโนมัติ เช่น rtvc_20261017_143005.wav โฟลเดอร์เริ่มต้นคือ recordings\ ในโฟลเดอร์โปรแกรม
  3. พูดได้เลย ปุ่มจะแสดงเวลาที่อัดไปแล้ว เช่น ■ Stop recording (12 s)
  4. กด ■ Stop recording (หรือกด Stop) เพื่อจบ หน้า Messages จะแสดงตำแหน่งไฟล์
  • ไฟล์ที่ได้คือเสียงที่ส่งออกไป Teams ทุกอย่าง รวมถึง gain ด้วย
  • รูปแบบไฟล์เป็น WAV 48 kHz, mono, 16-bit เปิดได้กับโปรแกรมเล่นเสียงทั่วไป
  • ระหว่างอัด เสียงยังส่งเข้า Teams ตามปกติ
  • ไฟล์อยู่ในเครื่องเท่านั้น ไม่มีการอัปโหลด และจะอัดก็ต่อเมื่อคุณกดปุ่มเท่านั้น
ขออนุญาตก่อนอัด ถ้าจะอัดเสียงคนอื่นในการประชุม ต้องขออนุญาตก่อน (ปุ่มนี้อัดเฉพาะเสียงของคุณที่แปลงแล้ว ไม่ได้อัดเสียงคนอื่นในประชุม)

12แก้ปัญหา

ดูหน้า Messages ก่อนเสมอ โปรแกรมจะบอกสาเหตุและวิธีแก้ในบรรทัดที่ขึ้นต้นด้วย ->

อาการวิธีแก้
สถานะเป็น Not configuredอ่านเหตุผลที่แสดงข้างสถานะ ส่วนใหญ่เกิดจากยังไม่ได้เลือก output ให้กด Use VB-CABLE
"VB-CABLE was not found"ติดตั้ง VB-CABLE แล้วรีบูต (หัวข้อ 03 ขั้น 3) จากนั้นกด Refresh devices
Error "Feedback loop"ช่อง Microphone เลือกเป็น CABLE Output อยู่ ให้เปลี่ยนเป็นไมค์จริง
Teams ไม่ได้ยินเสียงไมค์ใน Teams ต้องเป็น CABLE Output และ Output ในโปรแกรมต้องเป็น CABLE Input (ไม่ใช่ตัว 16ch) สถานะต้องเป็น Processing และแถบ Output ต้องขยับ ลองกด Test beep → output ด้วย
แถบ Input ไม่ขยับไปที่ Settings → Privacy & security → Microphone แล้วเปิดสิทธิ์ให้ desktop apps เช็กว่าเลือกไมค์ถูกตัว และไมค์ไม่ได้ถูกปิดเสียงด้วยปุ่มบนเครื่อง
เสียง robot หรือเสียงกระซิบใน Teams ขาดเป็นช่วงๆตั้ง Noise suppression ใน Teams เป็น Off หรือ Low
เสียงแตกหรือกระตุก และค่า underruns เพิ่มขึ้นเครื่องทำงานหนักเกินไป ให้ปิดโปรแกรมที่ใช้ทรัพยากรมาก หรือแก้ output_prebuffer_blocks ใน config.json จาก 1 เป็น 2 (ความหน่วงจะเพิ่มขึ้นประมาณ 50 ms)
"Could not open audio device"มีโปรแกรมอื่นจองอุปกรณ์ไว้ ให้ไปที่ Sound Control Panel → เลือกอุปกรณ์ → Advanced → เอาเครื่องหมายออกจาก Allow applications to take exclusive control หรือตั้งเป็น 48000 Hz
Error: device stopped / disconnectedไมค์หรือหูฟัง USB/Bluetooth หลุด ให้เสียบใหม่ กด Refresh devices แล้ว Start
คนอื่นได้ยินเสียงช้ากว่าปากขยับดูค่า Latency ในหน้า Voice ปกติประมาณ 120–180 ms (ไม่รวมความหน่วงของอุปกรณ์) ถ้าเพิ่งเกิดเครื่องสะดุด โปรแกรมจะลดกลับเองภายในไม่กี่วินาที (delay fixes เพิ่ม 1) ถ้ายังสูงค้าง ให้กด Stop แล้ว Start
คนอื่นในประชุมได้ยินเสียงตัวเองสะท้อนกลับSpeaker ใน Teams ตั้งเป็น CABLE Input อยู่ ให้เปลี่ยนเป็นหูฟังหรือลำโพงจริง
ได้ยินเสียงตัวเองสะท้อนMonitor ส่งเสียงออกลำโพงอยู่ ให้ใช้หูฟังหรือตั้ง Monitor เป็น (off)
หูฟัง Bluetooth เสียงแย่ลงทันทีBluetooth จะสลับไปโหมดคุณภาพต่ำเมื่อใช้ไมค์ของหูฟัง ให้ใช้ไมค์ในตัวโน้ตบุ๊กหรือไมค์แบบสาย/USB แทน
เครื่องเงียบหลังติดตั้ง VB-CABLEWindows เปลี่ยนลำโพงหลักเป็น CABLE Input ให้เลือกลำโพงหรือหูฟังจริงใน Settings → System → Sound
setup ขึ้นว่าไม่พบ py หรือ Python 3.12ติดตั้ง Python 3.12 64-bit ใหม่ โดยติ๊ก py launcher และ Add python.exe to PATH แล้วเปิด PowerShell หน้าต่างใหม่
setup ติดตั้งแพ็กเกจไม่สำเร็จตรวจอินเทอร์เน็ตแล้วรันใหม่ ถ้ายังไม่ได้ ให้รัน setup.ps1 -Recreate
เปิดโปรแกรมไม่ขึ้นเปิดผ่าน run.ps1 เพื่อดูข้อความผิดพลาด หรือรัน setup.ps1 ใหม่ แล้วดูรายละเอียดใน logs\rtvc.log
ปุ่ม Analyze กดไม่ได้ต้องมีเสียงครบทั้ง Reference และ Your voice และติ๊ก I confirm · ยืนยัน แล้ว
Record ในหน้า Voice from sample บอกให้ Stop processing ก่อนกด Stop ที่หน้า Voice ก่อน เพราะไมค์ใช้พร้อมกันสองงานไม่ได้
"Could not read the sample … decoder not installed"รัน setup.ps1 อีกครั้งเพื่อติดตั้งตัวอ่านไฟล์ WebM / M4A (PyAV)
"Preview failed: … virtual cable"ลำโพงหลักของ Windows เป็น CABLE Input อยู่ ให้เลือกหูฟังเป็น Monitor ในหน้า Audio devices
ผลการวัดมีคำเตือน ⚠ หรือเสียงใหม่ฟังไม่ใกล้ใช้ตัวอย่างที่ยาว 10–20 วินาที มีแต่เสียงพูดของคนเดียว ไม่มีดนตรี แล้ววิเคราะห์ใหม่ หรือปรับแถบต่อเองในหน้า Voice
อยากล้างค่าที่ตั้งไว้ทั้งหมดปิดโปรแกรมแล้วลบไฟล์ config.json (ไฟล์นี้เก็บแค่ค่าที่ตั้งไว้)

13อัปเดตและถอนการติดตั้ง

อัปเดตเป็นเวอร์ชันใหม่

  1. ปิดโปรแกรมก่อน
  2. ถ้าติดตั้งด้วย git: 
    git pull
    ถ้าติดตั้งด้วย ZIP: ดาวน์โหลด ZIP ใหม่ แล้วแตกไฟล์ทับโฟลเดอร์เดิม ไฟล์ config.json, recordings\ และ custom_voices\ ของคุณไม่อยู่ใน ZIP จึงไม่ถูกทับ
  3. รัน setup.ps1 อีกครั้งเพื่ออัปเดตไลบรารี

ถอนการติดตั้ง

  1. Parroty: ปิดโปรแกรม แล้วลบโฟลเดอร์โปรแกรมทั้งโฟลเดอร์ (รวม .venv) โปรแกรมไม่ได้ติดตั้งอะไรไว้ที่อื่นในเครื่อง ถ้าอยากเก็บไฟล์เสียงและเสียงที่สร้างไว้ ให้ย้าย recordings\ และ custom_voices\ ออกมาก่อน
  2. VB-CABLE (ถ้าไม่ใช้แล้ว): คลิกขวา VBCABLE_Setup_x64.exe → Run as administrator → Remove Driver → รีบูต
  3. Python 3.12 (ถ้าไม่ใช้แล้ว): Settings → Apps → Installed apps → Python 3.12 → Uninstall
